# Pharma Research & Education Hub

A free static academic resource website for pharmacy students, researchers and faculty.

## Cost model
This version is designed for a zero-cost launch using static hosting. GitHub Pages can publish static HTML/CSS/JavaScript from a repository; see the official GitHub Pages documentation.

## Important
This is NOT a journal and should not claim ISSN, DOI, Scopus, Web of Science, Impact Factor, peer-reviewed status, or indexing unless those facts genuinely apply to a separate service.

## Files
- `index.html` — website content
- `styles.css` — design
- `script.js` — navigation and demo form behavior

## Free deployment option
Create a public GitHub repository and upload these files. Enable GitHub Pages from repository Settings > Pages. GitHub's documentation describes the process and the default `username.github.io` address.

## Before collecting submissions
The contact form is a front-end demo only. Connect it to a suitable form service or backend before collecting personal information.
